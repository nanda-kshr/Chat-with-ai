# Chat with AI

## Privacy & Data Storage

- **No Backend Database / Leakage**: Nothing is stored in a database or leaked outside via the website.
- **Local Storage Only**: Everything is saved directly in your browser's `localStorage`.
- **Security Note**: The only possible risk is using the same browser to surf vulnerable or malicious websites.
- **Precaution**: In case you don't trust any website or extension you have installed, clear local storage before going.
